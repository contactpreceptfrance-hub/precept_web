Espace Administration pour l'équipe (Simple & Pratique)

Lien d'accès à l'espace d'administration
Pour vous connecter, rendez-vous sur : https://www.preceptfrance.fr/admin
Entrez votre mot de passe administrateur pour accéder à l'interface.

1. Le menu de navigation (Barre de gauche)

Onglet À quoi ça sert ?
📊 Tableau de bord Vue d'ensemble : ventes totales, commandes en attente, messages reçus.
📦 Commandes Toutes les commandes passées par les clients avec adresses de livraison.
📚 Livres & Catalogue Gérer vos 42 livres : modifier un prix, marquer un livre comme épuisé.
💬 Messages Messages et demandes reçus via le formulaire de contact du site.
⚙️ Paramètres Activer les paiements en mode Test ou en mode Réel (Production).

2. Comment traiter une commande reçue ?

  1. Dès qu'un client paye sur le site, sa commande apparaît dans Commandes (/admin/commandes).
  2. Le client reçoit automatiquement un email de confirmation, et l'équipe reçoit une alerte par email.
  3. Cliquez sur la commande pour voir :
    • Le nom et l'email du client
    • L'adresse de livraison complète
    • La liste des livres commandés et quantités
  4. Préparez le colis depuis le local (13 Rue Adèle, 92220 Bagneux) et déposez-le au transporteur (La Poste Colissimo, etc.).

3. Comment modifier le prix ou le stock d'un livre ?

  1. Allez dans Livres (/admin/livres).
  2. Cliquez sur le livre souhaité.
  3. Pour changer le prix : tapez le nouveau montant dans la case Prix (€) (ex. 11.99).
  4. Si le livre est en rupture de stock : cochez simplement la case « Épuisé (Sold out) ». Sur le site, le bouton passera en « Épuisé » pour empêcher les commandes. Décochez dès que vous recevez du stock.
  5. Cliquez sur Enregistrer. La mise à jour est immédiate sur le site !

4. Les extraits gratuits (Semaine 1)

Sur chaque fiche livre de la boutique, un bouton « Feuilleter un extrait gratuit (Semaine 1) » permet aux visiteurs de lire les premières leçons en PDF avant d'acheter. Tout est automatique.

5. Gérer les paiements Stripe

Dans Paramètres (/admin/parametres), vous pouvez basculer l'état de la boutique :

  • 🟡 Mode Test : Idéal pour tester sans argent réel avec la carte fictive 4242 4242 4242 4242.
  • 🟢 Mode Production : Le mode officiel pour recevoir les vrais paiements des clients sur le compte bancaire de l'association.

7. Questions fréquentes (FAQ)

❓ Un client n'a pas reçu son email de confirmation ?
Vérifiez dans Commandes que le statut est bien « Payée ». Demandez-lui de regarder ses Spams. Si besoin, renvoyez-lui un email manuel avec le récapitulatif affiché dans votre panneau admin.
❓ Où répondre aux personnes souhaitant rejoindre un groupe d'étude ?
Allez dans Messages (/admin/messages). Vous pouvez copier l'email du contact ou lui répondre directement depuis votre messagerie contact@preceptfrance.fr.
